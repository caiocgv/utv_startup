# CAD — Sistema de Plataforma de Carga

Arquivos CAD, modelos 3D e desenhos técnicos do sistema de Plataforma de Carga.

## Estrutura de Pastas

| Pasta | Descrição |
|-------|-----------|
| `draft/` | Arquivos em desenvolvimento, não aprovados |
| `approved/` | Arquivos oficialmente aprovados e liberados |
| `reference/` | Arquivos de referência (normas, modelos externos, etc.) |

## Convenção de Nomenclatura

```
SISTEMA-SUBSIST-COMP-vXX.step
```

Exemplo: `CARGO-PLATFORM-MAIN-FRAME-v01.step`
