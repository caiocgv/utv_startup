# REQ-0003 — Homologação DENATRAN

## Descrição

O UTV deve atender a todos os requisitos regulatórios do DENATRAN (Departamento Nacional de Trânsito) para circulação nas vias públicas brasileiras, incluindo os requisitos do INMETRO aplicáveis.
