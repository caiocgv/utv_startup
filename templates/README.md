## Como Usar

1. Copie o template desejado para o diretório destino
2. Renomeie o arquivo conforme a convenção
3. Preencha o front matter YAML
4. Complete as seções relevantes
5. Remova as seções não aplicáveis (mas mantenha o front matter completo)
6. Adicione links cruzados para documentos relacionados
