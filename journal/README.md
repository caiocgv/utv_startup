# Journal — Registro Diário

Registro diário das atividades de desenvolvimento da empresa.

---

## Filosofia

> "Nada pode existir apenas na memória. Toda informação deve estar registrada."

O journal é um diário técnico e de gestão. Registra:
- O que foi feito
- Horas dedicadas
- Problemas encontrados
- Decisões tomadas
- Próximos passos
