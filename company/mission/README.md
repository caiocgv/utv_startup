# Missão, Visão e Valores

## Missão

Desenvolver produtos de engenharia automotiva de alta qualidade para o mercado brasileiro, com rigor técnico, rastreabilidade total e foco no usuário final.

## Visão

Ser reconhecida como referência em engenharia de produtos utilitários no Brasil, com produtos que aliam robustez, modularidade e excelência técnica.

## Valores

| Valor | Descrição |
|-------|-----------|
| **Engenharia como ativo** | O conhecimento documentado vale mais que máquinas |
| **Integridade técnica** | Não comprometer segurança por custo ou prazo |
| **Rastreabilidade** | Toda decisão tem histórico e justificativa |
| **Modularidade** | Componentes compartilhados maximizam eficiência |
| **Melhoria contínua** | Cada protótipo ensina algo novo |
| **Produto nacional** | Priorizar fornecedores e componentes brasileiros |
